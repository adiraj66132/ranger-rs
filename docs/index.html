ranger-rs

A fast, Vim-powered terminal file manager written in Rust.

ranger-rs is a Rust reimplementation of ranger, the Vim-powered console file manager. It keeps ranger's keybindings and ideas but is rebuilt from scratch in Rust — no Python at startup.

Inspired by ranger (the original Python file manager) and yazi (the floating info panel on Tab).

Get started

# Clone
git clone git@github.com:adiraj66132/ranger-rs.git
cd ranger-rs

# Build
cargo build --release

# Run
./target/release/ranger-rs /path/to/directory

Or install:

install -m755 target/release/ranger-rs ~/.local/bin/ranger-rs
ranger-rs

Commands

Type them after : or /:

CommandAction
:qQuit
:cd <path>Change directory
:mkdir <name>Create directory
:touch <name>Create file
:openOpen selected file
:reloadReload directory
:hiddenToggle hidden files
:pwdShow current path
:theme <name>Switch theme
:themesList themes

Editors

Text files open in the first editor found on PATH:

  1. nvim
  2. vim
  3. vi
  4. nano
  5. emacs

If only nano or emacs is available, you'll see a suggestion to install vim or nvim.

Binary files (images, PDFs, etc.) open with xdg-open (open on macOS).

Config

Create ~/.config/ranger-rs/config.toml (see config.example.toml):

theme = "catppuccin-mocha"
show_hidden = false
preview_lines = 200
preview_bytes = 65536

Optional external previewers: rules are checked top to bottom, the first matching rule wins. The selected path is available as $RANGER_RS_PATH. If a command fails or times out, the built-in preview is used instead. 

[[scope]]
match = "*.pdf"
command = 'pdftotext -l 2 "$RANGER_RS_PATH" -'
timeout_ms = 1500

Themes

Built-in themes:

  • default
  • catppuccin-mocha, catppuccin-macchiato, catppuccin-frappe, catppuccin-latte
  • tokyo-night, tokyo-night-storm, tokyo-night-day
  • nord
  • dracula
  • gruvbox

Press T or run :theme <name> to switch. The picker shows a live preview; save your pick in ~/.config/ranger-rs/config.toml to keep it.

Plugins (not tested yet)

Lua plugins go in ~/.config/ranger-rs/plugins/*.lua. See plugins/example.lua.

ranger.register_command("hello", function(args)
    local name = args ~= "" and args or "world"
    ranger.notify("hello " .. name .. " from " .. ranger.cwd())
end)
ranger.register_key("H", "hello")

ranger.register_command("newdir", function(args)
    if args == "" then
        ranger.notify("usage: :newdir <name>")
        return
    end
    ranger.mkdir(args)
end)
ranger.register_key("N", "newdir")
