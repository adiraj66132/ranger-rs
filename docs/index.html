ranger-rs

From the ranger-rs wiki

ranger-rs is a Rust reimplementation of ranger, the Vim-powered console file manager. It keeps ranger's three-column layout and Vim keybindings but is rebuilt from scratch in Rust — no Python at startup.

Inspired by ranger (the original Python file manager) and yazi (the floating info panel on Tab).

Highlights: three-column miller layout, text and directory previews with configurable external previewers, editor and system-opener integration, a floating info panel, eleven themes, and Lua plugins.

Get started

Building from source needs Rust stable and a C compiler (Lua is vendored). Linux and macOS are supported. 

# Clone
git clone https://github.com/adiraj66132/ranger-rs.git
cd ranger-rs

# Build
cargo build --release

# Run
./target/release/ranger-rs /path/to/directory

With no path, ranger-rs starts in the current directory. --help and --version print information and exit.

Or install the latest prebuilt binary:

curl -fsSL https://raw.githubusercontent.com/adiraj66132/ranger-rs/master/install.sh | sh

This installs to ~/.local/bin and adds an rr shortcut, so typing rr opens ranger-rs in the current directory. Supported platforms: Linux x86_64/arm64 and macOS Intel/Apple Silicon.

From a checkout, ./install.sh --system installs to /usr/local/bin, and PREFIX=/opt/bin ./install.sh installs to a custom location.

Keys

KeyAction
j / kMove down / up
Ctrl-d / Ctrl-uJump 10 down / up
g / GTop / bottom
h / lParent directory / enter directory or open file
EnterEnter directory or open file
TabInfo panel (size, owner, MIME type, timestamps)
.Toggle hidden files
rReload directory
~Go to home
: or /Open the command line
TTheme picker
?Show key hints
q / Ctrl-cQuit

In the theme picker, j/k or the arrow keys cycle, g/G jump to the ends, Enter saves, and Esc/q cancels. On the command line, Esc cancels and Ctrl-u clears the input.

Commands

Type them after : or /:

CommandAction
:q, :quitQuit
:cd [path]Change directory (no path: home)
:mkdir <path>Create a directory
:touch <path>Create a file, or leave an existing file untouched
:openOpen the selected entry
:reloadReload the current directory
:hidden, :toggle_hiddenToggle hidden files
:pwdShow the current path
:helpShow the key hints
:theme [name]Switch theme (no name: open the picker)
:themesList built-in themes
:<name>Run a plugin command

Relative paths are resolved against the current directory, and a leading ~ expands to your home directory.

Editors

Files that look like text open in the first editor found on PATH:

  1. nvim
  2. vim
  3. vi
  4. nano
  5. emacs

If only nano or emacs is available, you'll see a suggestion to install vim or nvim.

Binary files (images, PDFs, etc.) open with xdg-open (open on macOS).

Config

Create ~/.config/ranger-rs/config.toml (see config.example.toml):

theme = "catppuccin-mocha"
show_hidden = false
preview_lines = 200
preview_bytes = 65536

Optional external previewers: rules are checked top to bottom, the first matching rule wins. The selected path is available as $RANGER_RS_PATH. If a command fails or times out, the built-in preview is used instead. 

[[scope]]
match = "*.pdf"
command = 'pdftotext -l 2 "$RANGER_RS_PATH" -'
timeout_ms = 1500

Themes

Built-in themes:

  • default
  • catppuccin-mocha, catppuccin-macchiato, catppuccin-frappe, catppuccin-latte
  • tokyo-night, tokyo-night-storm, tokyo-night-day
  • nord
  • dracula
  • gruvbox

Press T or run :theme <name> to switch. The picker shows a live preview; confirming a theme saves it to ~/.config/ranger-rs/config.toml.

Plugins

Lua plugins go in ~/.config/ranger-rs/plugins/*.lua and are loaded at startup. See plugins/example.lua. 

ranger.register_command("hello", function(args)
    local name = args ~= "" and args or "world"
    ranger.notify("hello " .. name .. " from " .. ranger.cwd())
end)
ranger.register_key("H", "hello")

ranger.register_command("newdir", function(args)
    if args == "" then
        ranger.notify("usage: :newdir <name>")
        return
    end
    ranger.mkdir(args)
end)
ranger.register_key("N", "newdir")

Run a registered command as :hello, or press its key in normal mode.

Available API:

FunctionMeaning
ranger.register_command(name, fn)Register a command; fn receives the argument string
ranger.register_key(key, command)Bind the first character of key to a command
ranger.notify(message)Show a message in the status line
ranger.cd(path)Change directory
ranger.quit()Quit
ranger.reload()Reload the current directory
ranger.toggle_hidden()Toggle hidden files
ranger.mkdir(path)Create a directory
ranger.touch(path)Create a file if it does not exist
ranger.cwd()Return the current directory

Commands registered by a plugin can be invoked from the command line, and keys are checked after the built-in bindings.
